변경 영향의 결과와 해석

같은 부품의 A/B를 연결하고 명목치 변경 4건을 얻었다: H1.X, H2.X, HORIZONTAL.PITCH, RIGHT.CENTER_MARGIN. 판·D홀의 특성 9개는 영향 없음이다. 전체 계획은 17개, 변경 계획은 9개이며 모든 항목은 not_started이다.

변경 계획에는 H홀의 위치 변경에 따라 지름·Y좌표 확인도 포함된다. 자동 홀 패턴 한 항목은 고정 요구사항과 연결되지 않아 추가 검토 대상으로 남는다. 공차·검사 방법은 null, 두 계획 모두 review_required다. 이것은 입력 연결 실패나 빈 blocked 계획과 다르지만, 검사 수행 가능·완료·승인을 의미하지 않는다.

요구값을 저장 STEP 측정값과 먼저 대조한다. H1.X의 요구값만 131로 바꾼 별도 반례는 실제 측정 130과 달라 review CLI 호출 전에 거절됐다. 원본 CAD 입력, 이전 산출물, canonical readiness와 검사 증거는 변경하지 않았다.

JSON 후속 경로의 확인

JSON과 TOML을 모델 미리보기에서 동일한 정규화·스키마 검증으로 처리한다. 모델에서 도면으로 넘기거나 추적 create/draw/report를 요청할 때도 JSON 텍스트를 TOML로 잘못 읽지 않는다. 추적 작업은 기존 실행기가 정규화된 설정을 JSON으로 저장하는 방식을 그대로 사용한다. 잘못된 JSON의 모델·도면 요청은 HTTP 400으로 응답한다.

실제 브라우저에서 JSON 원본의 WIDTH 주석만 150으로 바꾼 도면은 QA 89, 품질 fail, 근거 연결률 80%, WIDTH 미연결이었다. 형상 폭은 142를 유지했다. 이후 브라우저 보고서는 화면 안내대로 원본 설정 142로 생성됐으며 overall status는 incomplete였다. 해당 보고서는 create 품질·drawing 품질·DFM 자료를 받지 못했다. 보고서와 tracked create에 없는 품질 판정을 새로 만들어 통과로 표시하지 않았다. 그 실행의 UI 요약 결과 없음은 분석 완료의 근거가 아니다.

후속 실행에서는 새 출력 폴더에서 strict create·draw를 수행하고 report --dfm에 세 자료를 모두 제공했다. 보고서는 overall 92 / pass, DFM은 95점과 경미한 경고 1건이었다. 이는 별도 CLI 실행의 결과이며 이전 브라우저 작업을 수정하거나 UI 보고서 경로가 자동 수집하도록 고친 것이 아니다. 공학 검토와 근거에 실행 구분, 패턴 대응, DFM의 한계와 PDF 레이아웃 관찰을 기록한다.

검증의 범위

  • 원래 코드의 실패를 재현한 뒤 관련 Node/Python 회귀 검사를 실행했다. STEP 진입점·import 안전성과 실제 오류 fallback, JSON/TOML 동등성·잘못된 입력·금지된 키·도면 편집/저장 연결을 확인했다.
  • 모델·도면 생성, STEP/SVG 측정, 리비전 비교와 계획은 실제 로컬 FreeCAD 1.1.3 및 기존 CLI를 사용했다.
  • 브라우저는 실제 파일 선택과 모델·도면·추적 작업을 수행했다. 검사 조합 전체나 다른 OS에서의 성공을 보장하지 않는다.
  • 전체 테스트·최종 읽기 전용 검토·묶음 링크와 체크섬 결과는 제공 묶음의 검증 기록에 실행 시각과 함께 보관한다. 생성물은 output/, 작업 로그는 tmp/codex/에 둔다.

남는 직접 확인과 범위 밖 작업

실제 USB 허브 치수·장착·재질·하중·제조 공차·검사 방법은 확인하지 않았다. 실제 검사값·제조 승인·검사 증거 첨부도 없다. 본인 기여와 설계 판단은 발표자가 실제 수행 범위로 설명해야 한다. 제품 내 유료 AI API, 동영상 녹화, 다른 OS/타인 PC의 실사용 검증은 하지 않았다.

형상에 따라 변하는 자동 패턴 ID의 일반적 동일성 매칭은 별도 확장 범위다. 이 사례에서는 해당 불확실성을 계획에 유지한다. 새로운 플랫폼이나 분석 기능을 포트폴리오 v1의 필수 조건으로 추가하지 않는다.

처음 제공한 묶음은 commit·push·PR·배포 전의 기록이다. 후속 공개 자료는 해당 소스 커밋과 PR을 별도로 명시하며, master 병합이나 실물 검사 완료를 의미하지 않는다. 사례 설명, 시연 대본, 기여 기록에서 시작하면 된다.
