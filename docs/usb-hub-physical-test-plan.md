# USB 허브 R1 장착·조작 하중·열 시험 계획

상태: 시험 준비 문서. 실제 장착, 체결, 통전, 하중·열 시험은 수행하지 않았다. 현재 실물 제품과 받침면이 특정되지 않아 실행 조건은 미확정이다.

2026-09-16에 실제 ChatGPT UI에서 **6 Pro** 모드를 선택해 기준 설계·제조사 자료와 조작 하중·장착·열 시험 지침을 질의하고 최종 답변을 받았다. 아래는 답변을 1차 자료와 대조해 정리한 계획이다. AI 자문과 CAD 검사는 실물 계측이나 인증을 대신하지 않는다.

## 1. 기준 설계와 자료

[R1 기준 설계](usb-hub-reference-mount.md)의 장착판은 142×74×4 mm, 재료 후보는 6061-T6이다. 허브용 M3와 받침면용 M5, 10 mm 스페이서, 2 mm 패널은 공칭 조립 검토에 사용한 구성이다. 실제 재료·패널·체결재·토크가 확정된 사양은 아니다.

## 2. 단계별 시작 조건

| 단계 | 필요한 입력과 현장 확인 | 지금 준비할 수 있는 일 |
|---|---|---|
| 무전원 가조립 | 실제 제품/판/패널 식별, 치수·상태, 전원 분리, 임시 지지, 현장 수행자 | 도면·좌표·부품 목록과 체크 순서 작성 |
| 최종 체결 | 나사/너트 강도 등급, 표면처리·윤활·잠금 방식, 좌면, 유효 물림, 패널 국부 압축, 해당 조인트의 토크 근거 | 각 입력을 기록할 표와 미확정 항목 준비 |
| 조작력·정적 하중 | 실제 사용 방향과 케이블, 힘 작용점, 부품 제한, 지그 용량, 힘/변위 계측, 중단·판정 한계 | 하중 사례, 좌표 변환, 로그 필드 정의 |
| 통전·열 시험 | 전원·극성·케이블·포트/전체 전력 범위, 작업 부하, 센서, 주변·부품별 온도 한계, 차단·냉각 방법 | 대조/장착 시험 조건표와 USB 오류·무결성 기록 준비 |

미확정 항목 때문에 한 단계를 시작할 수 없어도 앞 단계의 문서 준비는 계속한다. 토크 근거 없이 최종 체결하거나, 부품 한계 없이 하중을 높이거나, 전기 조건 없이 통전하지 않는다. 외주 의뢰는 이 계획의 선행 조건이 아니다. 실제 물리 작업에는 현장 사람과 적절한 계측·지그가 필요하다.

## 3. 무전원 장착과 체결 확인

1. 실제 허브 모델/리비전, 판과 패널, 케이블·체결재를 식별하고 사진·치수·재료 근거를 연결한다. 부품 무게는 실제 구성으로 계측한다.
2. DC와 USB를 포함한 모든 전원 유입 경로를 분리하고 허브·장착판을 임시 지지한다. 모서리·버·균열·구멍·좌면을 확인한다. 플랜지 접시형 구멍과 제안한 평와셔/볼트 머리가 맞는지 확인한다. CAD의 체적 겹침 검사만으로 좌면 접촉을 판정하지 않는다.
3. 도면의 좌측 하단을 XY 기준으로 지정한다. 허브 접촉면을 Z=0, 허브 방향을 +Z로 표시한다. 모서리의 버·모따기를 원점으로 쓰지 않고 직선 기준의 연장 교점을 사용한다. 이 실물 Z 기준과 CAD 좌표의 관계도 기록한다. 구멍 배열과 패널 지지 위치를 확인한다. 구멍을 억지로 맞추거나 볼트로 끌어당겨 변형시키지 않는다.
4. 모든 볼트를 느슨하게 넣고 스페이서·와셔·너트의 쌓임, 평행 접촉, 공구 접근, 케이블 삽입 공간과 굽힘 경로를 확인한다. M3 끝–패널 간격과 뒷면 돌출량은 실물에서 측정한다.
5. 체결재 공급자/제품의 해당 조인트 지침 또는 재료·윤활·물림·좌면을 반영한 검토로 토크 범위를 정한다. M3/M5 지름만으로 일반 토크표를 적용하지 않는다. 근거가 없으면 가조립 상태에서 멈춘다. [Bossard 체결 지침](https://assets.eu.ctfassets.net/0vp0u5uh75zd/3S40LEUM235Qk3rJk2phR1/c715f9f45232756c12b59aa681c7fede/060_074_Preload_tightening_torques_Fastening_EN_01_2025.pdf)의 표도 마찰·공구 조건을 가정하며, 좌면 압력과 외력 후 잔류 체결력 검토를 요구한다.
6. 근거가 확보되면 지정 순서와 토크로 체결하고 공구 ID·설정·실행 기록을 남긴다. 볼트 머리/너트와 고정부에 풀림 확인 표식을 남기고 초기 간극·상대 위치·처짐을 기록한다.

판의 제작 치수공차·위치공차·평면도는 기능상 필요한 값으로 별도 확정한다. 제조사 허브 도면의 ±0.15 mm나 CAD 비교의 0.10 mm를 장착판 실물 합격 기준으로 자동 적용하지 않는다. 볼트가 들어간다는 사실과 구멍 중심의 계측 적합성도 구분한다.

## 4. 조작 하중의 정의와 측정

판의 X/Y는 도면과 같고 +Z는 판에서 허브 쪽 법선이다. 실제 장착 방향에 따른 중력 방향을 기록한다. 하중마다 힘 벡터 `F`, 작용점, 기준점에서 작용점까지의 거리 벡터 `r`을 기록한다. 모멘트는 `M = r × F`로 계산하며 mm를 m로 바꾸어 N·m로 기록한다. P 구멍군 중심의 XY는 `[71,37]`이고 받침판 지지 평면의 Z는 실제 적층으로 정한다. 10 mm 스페이서 높이만 모멘트 팔로 쓰지 않는다.

| 사례 | 확보할 근거 | 시험에서 재현할 조건 |
|---|---|---|
| 전체 조립체 자중 | 실제 질량, 무게중심 또는 그 불확도, 장착 방향 | 실제 지지·고정 방식과 케이블이 전달하는 자중 |
| USB 삽입/분리 | 실제 upstream/downstream 포트·케이블 조합별 정상 조작력 | 커넥터 축 방향, 실제 손잡이 위치, 삽입과 분리 각각 |
| 전원 커넥터 삽입/분리 | 실제 DC 플러그의 정상 조작력과 제조사 제한 | 무전원 상태의 축 방향 조작, 케이블 몸통을 잡아 빼지 않음 |
| 사용 중 케이블 당김 | 실제 배선 방향·고정점·예상 사용 시나리오 | 현실적으로 생기는 ±X/±Y/±Z 성분과 힘 작용점, 스트레인 릴리프의 하중 경로 |
| 결합 하중 | 동시에 발생하는 자중·조작·케이블 힘 | 성분과 모멘트를 합산. 서로 동시에 발생하지 않는 최대값을 임의로 모두 합치지 않음 |

커넥터 정상 조작력은 허브를 별도로 안정적으로 지지한 구성에서, 적절한 힘 센서로 실제 조합을 측정한다. 저항이 비정상적으로 커지거나 정렬이 틀어지면 중단한다. 최대 삽입력 등의 범용 USB 수치를 이 제품의 허용 옆당김 하중으로 바꾸지 않는다. 케이블 옆당김/굽힘 시험은 커넥터와 케이블의 제한을 먼저 확인한다.

서비스 하중은 정상 사용 측정값, 측정 불확도, 사용 시나리오, 제품 제한을 함께 검토해 결정한다. 소수 반복의 최대값만으로 수명 전체나 모든 사용자를 대표한다고 주장하지 않는다. 제한이 없는 사례는 정량적인 실물 시험하중을 미확정으로 두고 CAD 민감도 분석용 가정만 별도 기록한다.

H 체결부는 허브와 그에 전달되는 케이블 하중, P 체결부는 장착판을 포함한 전체 하중을 받는다. 실제 자중이 이미 작용하는 시험에서 같은 무게의 추를 더해 자중을 중복 인가하지 않는다. 장착판만 시험하기 위한 더미 하중 전달구는 실제 하중 경로를 재현해야 하며, 그 결과로 실제 허브 플랜지·커넥터까지 검증했다고 주장하지 않는다.

## 5. 하중 시험 절차와 중단 조건

1. 실제 패널·지지 간격·체결 방식·방향을 재현한다. 떨어지는 부품을 받을 독립 지지와 지그 용량을 확인한다. 낙하 방지 장치는 정상 측정 중 하중을 분담하지 않도록 하고, 작동했다면 그 사실을 기록한다.
2. 힘 센서의 범위·분해능·교정·영점, 변위 센서의 독립 기준, 지그/패널 변형, 시간 동기화와 표본화율을 확인한다. 짧은 삽입 피크를 놓치지 않도록 실제 조작 속도로 수집 성능을 확인한다.
3. 부품별 한계와 허용 처짐·간극·슬립을 바탕으로 각 사례의 목표 힘, 증가 속도, 유지시간, 반복횟수, 제하시간, 잔류변형 판독 시점을 **시험 전에** 정한다. 절차 제안값과 실제 채택값·선정 근거를 분리한다.
4. 무부하 기준을 기록하고 힘을 서서히 올린다. 단계마다 힘·변위·패널/지그 움직임·간극·USB 연결 상태(해당 시)를 기록한다. 흔들기·충격·과하중을 추가하지 않는다.
5. 유지 후 완만하게 제하한다. 사전에 정한 시점의 잔류변형, 볼트 표식, 좌면·패널 압흔과 케이블/포트 상태를 확인한다. 중간 재체결·영점 재설정은 숨기지 말고 이벤트로 기록한다.

다음 상황에서는 즉시 하중 증가를 멈추고 안전하게 제하한다: 설정한 힘/변위/간극 한계 도달, 센서 범위 이탈·로그 손실, 지그 이동, 갑작스러운 강성 저하·슬립·기울어짐, 균열/영구 눌림, 체결 풀림, 커넥터 손상 징후. 사람이 낙하 경로나 가압점에 손을 넣어 받치지 않도록 지지한다.

계측 이상으로 중단한 시험은 `unknown` 또는 무효 기록이다. 실제 손상이 관찰되면 해당 요구조건의 `fail` 근거로 남긴다. 짧은 정적 반복은 피로 수명이나 진동·충격 내구 검증이 아니다.

회전 표식이 그대로여도 체결축력이 유지됐다고 판정하지 않는다. 제하 후 영점을 다시 맞추어 잔류변형을 지우거나, 기록 전에 재체결해 풀림을 감추지 않는다. 축력을 측정하지 않았다면 축력 유지 여부는 별도 미확인 항목이다.

### Pro가 제안한 초기 관찰 절차 — 아직 채택하지 않은 후보값

아래 수치는 제조사 정격·표준시험·안전율이 아니다. 각 시험편의 목표 외력과 중단 한계가 확정되고 지그·계측 성능을 확인한 뒤 사례별 계획에 채택 여부와 근거를 기록한다. **현재 목표 외력 N, 토크 N·m는 미확정이다.**

| 항목 | Pro 제안 후보 | 적용 조건 |
|---|---|---|
| 정상 삽입/분리 관찰 | 실제 조합별 각각 3회 | 별도 안정 지지, 정상 조작 범위. 최대 힘의 통계적 보증이 아님 |
| 외력 증가 | 목표 외력의 0→25→50→75→100% | 추가 외력 기준. 실제 자중은 유지 |
| 상승/유지 | 상승 단계마다 10초 이상, 중간 단계 30초, 목표에서 60초 | 중단 조건이 항상 우선 |
| 제하 | 100→75→50→25→0%로 완만하게 감소 | 제하 시간은 사례별 지정 |
| 잔류변형 판독 | 추가 외력 제거 후 60초, 600초 | 초기와 같은 자중·방향·기준 유지 |
| 초기 정적 반복 | 사례별 3회 | 피로·수명 시험으로 해석하지 않음 |
| 조작력 수집 | 100 Hz 검토 | 실제 센서 응답과 조작 피크 포착 가능성을 먼저 확인 |

## 6. 비장착 대조와 장착 상태의 열 시험

같은 허브·전원·호스트·케이블·주변 장치·USB 작업 부하·장착 방향·주변 환경으로 비교한다. 비장착 대조의 임시 지지는 통풍을 막거나 큰 방열 경로가 되지 않도록 정의한다. 장착판이 추가되는 것 외에 달라진 조건을 기록한다.

- 센서 위치: 주변 공기(케이스/배기 열의 직접 영향 제외), 판과 패널 사이 공기, 허브의 대표 고온 부위, 장착부 근처 외부 면, 장착판, 패널, 전원/USB 커넥터. 위치·부착 방법·센서 ID를 사진에 대응시킨다. 접촉면 사이에 센서를 끼워 간극·열전달이 바뀌면 별도 시험 구성으로 식별한다.
- 반짝이는 금속을 적외선 온도계의 기본 방사율로 읽어 확정 온도로 쓰지 않는다. 적합한 접촉 센서를 사용하거나 방사율·반사·표면 처리의 영향을 검토한다. [FLIR 측정 지침](https://support.flir.com/docdownload/assets/web/27eh/en-us/T505000.xml.html)은 방사율·반사 온도 등의 보정 필요성을 설명한다. 센서 부착물로 환기구를 가리거나 전기 단락을 만들지 않는다.
- 제품의 0–55 °C 동작환경 표기는 케이스·케이블·패널의 표면 허용 온도가 아니다. 각 부품의 온도 한계와 센서 오차를 따로 설정한다. 표면 한계가 없으면 온도 상승 비교는 할 수 있어도 절대 적합성은 `unknown`이다.
- 전원은 해당 실제 제품의 전압·극성·어댑터 정격을 확인한다. 포트별 2 A 표기만으로 모든 포트에서 동시에 최대 전류를 인가하지 않는다. 전체 전력 예산, 포트/케이블 정격과 허용된 부하를 확인한다. 어댑터 정격이나 USB로 전달한 전력을 허브의 발열량으로 취급하지 않는다.

절차는 초기 냉각/주변 상태 기록 → 비장착 대조의 무부하·의도한 실제 작업 부하 → 냉각 → 장착 상태의 같은 부하 순서다. 지속 시간, 안정화 판정 창과 온도 변화 기준, 최대 관찰시간, 환경 일치 기준은 사전에 정한다. 안정화되지 않은 채 종료한 결과를 정상상태 온도로 기록하지 않는다. 필요한 경우 대조 조건을 다시 측정해 환경 드리프트를 확인한다.

Pro의 초기 비교 후보값은 다음과 같다. **미채택 제안값**이며 제품 온도 한계를 의미하지 않는다. 같은 허브로 A1 비장착 → B1 장착 → A2 비장착을 비교하고, 온도 수집은 1초 간격, 비교 구간의 주변온도 차이는 1 °C 이내를 목표로 한다. 모든 핵심 측정점의 절대온도와 주변 대비 상승온도 `ΔT` 각각의 변화율 **절댓값**이 0.1 °C/분 이하인 상태가 연속된 10분 창 2개에서 유지되는지 본다. 센서 드리프트·분해능으로 이를 분별할 수 있고 주변온도·부하도 안정적이어야 한다. 그 뒤 같은 부하로 30분 더 관찰한다. 감독 가능한 최대 관찰시간(예: 2시간)을 먼저 정하고 그 안에 완료하지 못하면 안정화 미확인으로 남긴다. 실온 비교를 55 °C 환경의 검증으로 외삽하지 않는다.

`ΔT = T_surface − T_ambient`, 장착 효과는 `ΔT_B − ΔT_A`로 정리한다. 비교 불확도보다 작은 차이는 이번 측정으로 구분하지 못한 것으로 보고한다. B가 A보다 차가워도 부품별 절대 온도 한계가 모두 충족된다는 뜻은 아니다.

온도와 함께 입력 전압·전류, 가능한 포트별 전압·전류, 전송량·처리율, 연결 해제/재연결, 호스트 오류, 데이터 체크섬을 같은 시간축에 남긴다. 업무용 원본 데이터 대신 복구 가능한 시험 데이터를 사용한다. 작업 부하가 다른 온도 기록을 직접 비교하지 않는다.

저장장치는 쓰기 완료·캐시 반영 뒤 재읽어 기대 해시와 비교한다. 의도한 분리·절전·리셋은 별도 이벤트로 남긴다. [Linux usbmon 문서](https://docs.kernel.org/usb/usbmon.html)도 호스트 드라이버 요청 기록과 실제 버스 트랜잭션의 차이를 명시한다. OS 로그에서 오류를 못 찾았다는 결과를 물리계층 오류율 0이나 USB 인증으로 바꾸지 않는다.

부품별 사전 한계 접근/초과, 예기치 않은 온도 상승, 냄새·변색·연화, 전원 불안정, 센서 이탈, 데이터 손상·반복 연결 오류가 생기면 정해진 방법으로 작업 부하를 중단하고 전원을 차단한다. 접촉 가능한 온도까지 냉각한 뒤 외관·체결·기능을 재확인한다. 뜨거운 상태에서 무리하게 재체결하거나 덮어서 냉각하지 않는다.

온도 중단선에는 계측 불확도와 차단 지연 중 상승 여유를 반영한다. 정상 종료는 쓰기 완료·안전한 분리를 거치고, 위험 징후가 있으면 데이터 완료보다 차단이 우선이다. [제품 사양](https://www.coolgear.com/product/4-port-usb-3-2-gen-2-mini-powered-hub-w-esd-surge-protection-power-adapter)에 버스 전원 지원이 있으므로 DC 어댑터만 뽑고 무전원이라고 판단하지 않는다. 업스트림 등 모든 유입 경로를 확인해 분리한다. 상용전원 측을 개조하거나 보호기능을 우회하는 계측은 이 계획에 포함하지 않는다.

## 7. 판정과 불확도

[NIST 측정 불확도 설명](https://www.nist.gov/itl/sed/topic-areas/measurement-uncertainty)에 따라 분해능만이 아니라 교정, 영점·드리프트, 반복성, 정렬, 지그·온도 영향 등 측정 대상에 필요한 불확도 요인을 기록한다. 아래는 이 프로젝트의 **판정 규칙 제안**이며 NIST가 이 제품의 합격 기준을 정했다는 뜻이 아니다.

| 상태 | 의미 |
|---|---|
| `pass` | 실제 수행한 유효한 시험에서, 근거가 확정된 해당 기준을 측정 불확도까지 고려해 충족 |
| `fail` | 유효한 측정으로 기준을 벗어나거나, 해당 요구조건에서 허용하지 않은 손상/풀림/기능 이상을 확인 |
| `unknown` | 기준·제품 식별·계측 근거가 없거나, 측정 구간이 경계와 겹치거나, 시험이 무효/중단되어 판정 근거가 부족 |
| `not_tested` | 해당 실물 시험을 시작하지 않음 |

상한 L과 측정값 y, 확장불확도 U에 대해 `y + U ≤ L`이면 그 상한 조건의 통과 근거로 삼고, `y − U > L`이면 초과 근거로 삼는다. 경계와 겹치면 `unknown`으로 남긴다. 하한·양측 한계도 측정 구간 전체로 판단한다. 이 규칙을 채택할 책임자와 근거를 기록하고, 측정 한계를 넘어선 정밀도를 표시하지 않는다.

`U = k × u_c`를 사용한다면 분포·자유도·포함인자 k의 근거를 함께 적는다. k=2라는 이유만으로 언제나 정확히 95%라고 쓰지 않는다. [NIST TN 1297 §6](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-6-expanded-uncertainty). 중단 한계는 이 합격/불합격 판정과 별개로 더 일찍 작동하도록 정한다.

순간 변형, 제하 후 잔류변형, 조인트 슬립, 최소 간극, 온도, USB 무결성은 각기 판정한다. 필수 항목에 `unknown` 또는 `not_tested`가 있으면 전체를 `pass`로 집계하지 않는다. 한 구성/방향/작업 부하에서의 통과는 검증한 범위에만 적용한다.

## 8. 기록 양식과 역할

[계획용 JSON 양식](templates/usb-hub-physical-test.template.json)은 실행 코드나 검사 증거가 아니다. 실제 조건을 별도 실행 폴더의 사본에 채우고, 센서 원본 파일·UTC 시각·계측기 교정·사진·변경 이벤트를 연결한다. 결측값은 `null`과 유효성 사유를 기록한다. 측정되지 않은 값을 0이나 CAD 값으로 채우지 않는다.

최소 기록에는 구성/리비전, 현장 수행자, 사례별 힘 벡터·작용점·모멘트, 램프/유지/제하와 반복, 힘·변위·간극, 주변/표면 온도, 실제 전기 작업 부하, USB 오류·체크섬, 중단 이벤트, 불확도와 기준 출처가 포함된다. 물리 기록을 저장소 검사 자료로 제출할 때는 기존 [inspection-evidence 계약](inspection-evidence-contract.md)의 원본·권한·무결성·리비전 검토 절차를 사용한다. 이 계획용 양식을 새 검사 증거 계약으로 취급하지 않는다.

| 담당 | 실제 가능한 일 |
|---|---|
| AI/저장소 | 출처 대조, CAD/계산의 한계 표시, 계획·기록 양식 작성, 실제 입력값 계산, 제공된 센서 로그 분석과 보고 |
| 연결된 계측기 | 실제 힘/변위/온도/전압·전류 수집. 장치·인터페이스·교정·시계가 확인된 뒤에만 자동 수집 가능 |
| 현장 수행자 | 실물 식별, 지그 설치, 체결·케이블 조작, 센서 부착, 통전·하중 인가, 중단·제하·냉각과 육안 확인 |

현재 연결된 센서·제어 장비나 현장 수행자는 확인되지 않았다. 이 문서를 작성한 사실은 실물 감독·원격 제어를 수행했다는 증거가 아니다.

향후 수집기를 연결하더라도 현장 차단이 네트워크나 AI 응답을 기다리게 하지 않는다. 시험 대상 허브가 끊겨도 기록이 유지되도록 로거 경로를 분리한다. 원본 파일 경로·SHA-256, 결측 구간, 계획 변경 시점과 담당자를 남긴다. 빈 배열은 미기록을 뜻하며 오류 0건을 뜻하지 않는다.

## 9. 다음 순서

1. 실제 허브 리비전과 패널 재질·두께·지지 조건을 확보해 기준 설계 적용 여부를 정한다.
2. 플랜지 좌면, M3/M5 체결 구성·토크 근거, 실제 간극과 케이블 접근을 무전원 상태에서 확인한다.
3. 실제 케이블 조합의 정상 조작력과 사용 방향을 측정해 사례별 힘·모멘트 및 중단/판정 한계를 정한다.
4. 계측기·지그를 갖추어 정적 시험을 수행하고 원본 로그를 검토한다.
5. 실제 허용 전기 부하·온도 한계를 확정해 대조/장착 열 시험과 USB 무결성 확인을 수행한다.

현재 설계에서 우선 확인할 취약점은 얇은 허브 플랜지의 볼트 좌면, 패널의 국부 눌림·변형과 고정 방식, 케이블 당김 모멘트, 열에 따른 주변 부품 영향이다. 공칭 구멍 중심 일치만으로 이 항목들이 해결되지는 않는다.
