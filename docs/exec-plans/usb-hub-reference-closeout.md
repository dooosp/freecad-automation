# USB 허브 기준 설계 자동 검토 마무리

사용자의 2026-09-17 “나머지 계획을 모두 자동으로 끝까지 진행” 요청에 따라 기존 Coolgear 기준 설계의 남은 자료 조사·계산·검증·전달을 완료한다. 기존 실제 ChatGPT 6 Pro 자문을 이어 사용하며, 기준 설계·공칭 CAD·실물 증거를 구분한다.

- [x] 볼트 머리→와셔→플랜지의 위·아래 CAD 접촉 면적과 맞물리는 투영 영역을 확인한다.
- [x] 확인된 공차만으로 계산 가능한 항과 아직 산출할 수 없는 전체 최악조건을 구분한다.

## 이번 자동 실행의 종료 기준

모든 위 항목에 실제 근거와 결과를 연결하면 기준 설계의 자동 검토·준비 작업을 종료한다. 실물 제품·받침면·체결품 로트·계측기·현장 수행자가 확인되지 않은 상태에서는 실제 장착·조작력·하중·열 시험, 제조/실사용 승인을 완료로 표시할 수 없다. 그런 항목은 이유와 필요한 입력을 최종 판정표에 남긴다.

일반적인 기능 확장, master 통합 계획, 외주·주문·업체 연락은 이 기준 설계 마무리 범위에 포함되지 않는다. 기존 R1와 M3×10 후보의 원본 파일·과거 압축 자료를 보존한다.

## Git 전달과 검증 기록

위 검토 뒤 같은 브랜치에 정상 커밋·푸시하고 원격 SHA를 확인한다. 자기 커밋 SHA를 소스 파일 안에 미리 만들지 않으며, 실제 커밋·원격 SHA·푸시 여부는 최종 산출물의 `verification.json`에 실행 후 기록한다.

검증 결과: FreeCAD 형상 9개, 후보 재읽기/보존 9개, 좌면 10개 통과. 로컬 링크 49개, 출처/결과 해시, 원본 R1 보존, 미수행 상태와 빈 기록 양식 검증 통과. 검토 화면의 DOM과 화면 배치를 확인했다. JSON 직접 열기는 앱 브라우저에서 `ERR_BLOCKED_BY_CLIENT`가 발생해 성공으로 기록하지 않는다. JSON 파일은 검증한 배포 묶음에 포함한다.
