# Coolgear 기준 설계 통합 패키지

사용자는 2026-09-17 **실물이 없으며 기존 Coolgear 기준 설계로 진행**한다고 확인했다. 현재 작업 범위는 기준 형상·도면·부품표·계산과 재현 자료다. 실물 준비나 측정값 제출을 현재 작업의 완료 조건으로 두지 않는다.

현재 참조할 구성은 **장착판 R1 + M3×10 조립 형상 후보 + 기존 평와셔**다. 원본 R1의 M3×12 구성과 넓은 NBK 와셔 비교안은 보존된 검토 이력이다. 이 구성 선택은 실사용 적합성이나 제조 승인을 뜻하지 않는다.

기계 판독 기준은 [기준 구성 JSON](reference-data/usb-hub-reference-baseline.json), 부품 사양의 출처는 [제조사 후보 자료](reference-data/usb-hub-fastener-candidates.json)다. 형상·부품표에서 어떤 값이 설계 선택이고 어떤 값이 가정인지 유지한다.

## 기준 부품표

| 항목 | 수량 | 기준 형상·사양 | 카탈로그 후보 품번 |
|---|---:|---|---|
| 기준 허브 | 1 | Coolgear CG-U3MINI4PH-G2 | 기준 모델 / 설계·가정 |
| 장착판 R1 | 1 | USB-REF-R1, 142×74×4 mm | 기준 모델 / 설계·가정 |
| 가정 받침판 | 1 | 142×74×2 mm | 기준 모델 / 설계·가정 |
| 가정 스페이서 | 4 | 내경 5.5 / 외경 10 / 길이 10 mm | 기준 모델 / 설계·가정 |
| 허브 볼트 후보 | 4 | M3×10 | 07160-03X10 |
| 받침판 볼트 후보 | 4 | M5×25 | 07160-05X25 |
| 허브 너트 후보 | 4 | M3, H 최대값 2.4 mm 적용 | 07210-03 |
| 받침판 너트 후보 | 4 | M5, H 최대값 4 mm 적용 | 07210-05 |
| 허브 평와셔 후보 | 8 | 내경×외경×두께 3.2×7×0.5 mm | 07300-03 |
| 받침판 평와셔 후보 | 8 | 내경×외경×두께 5.3×10×1 mm | 07300-05 |

10개 행의 수량 합계 39개는 조립 CAD 객체 수와 대조한 값이다. 허브 내부의 51개 솔리드를 51개의 별도 구매품으로 세지 않는다. 카탈로그 품번은 형상 후보를 식별하며 실제 체결품 로트·등급·공차의 검사 결과가 아니다. 너트 높이는 H 최대값을 썼다. 패널과 스페이서의 실제 재질·제품은 미확정 가정이다.

## 하나로 연결한 산출물

- 선택한 조립 형상 후보: FCStd와 STEP, 해당 CAD에서 만든 미리보기.
- 장착판 R1: STEP·BREP·STL, A3 SVG 도면, 입력 JSON.
- 기준 부품표: 수량·품번·CAD 객체 연결이 있는 JSON과 표.
- 검토 이력: 모델/도면 품질, 허브 기준 구멍 비교, 체결 길이·좌면·편심 검토, Pro 자문 반영 요약.
- 재현 자료: 원본 입력 CAD, 검증 스크립트, 파일 해시, 실행 및 Git 확인 기록.
- 향후 참고 자료: 실물 시험 절차와 빈 기록 양식. 현재 수행 범위에는 포함하지 않는다.

로컬 산출물은 `output/usb-hub-reference-mount/reference-dossier/`다. `index.html`을 시작 화면으로 사용한다. 과거 `closeout/`와 `eccentricity/`는 이 패키지의 `evidence/` 아래에 보존본으로 포함한다. 과거 보고서의 물리 시험 착수 조건은 향후 실물 단계에서 적용한다.

## 확인한 정합성

새 FreeCAD 읽기 전용 검사 10개 항목을 통과했다. 기준 부품표의 모든 객체 이름·수량이 선택한 CAD와 일치했고, 39개 객체/89개 솔리드를 확인했다. 네 M3×10 후보의 끝·머리 위치와 원본 보존을 확인했다. 별도 장착판 STEP·BREP와 조립 모델 속 판의 양방향 차집합 체적은 0 mm³였다. 같은 검사를 패키지의 독립 실행 스크립트로 재현했다.

기존 모델 품질은 `pass`, 도면 품질은 `pass`/91점, 필수 치수 추적률은 100%, 허브 기준 구멍 비교는 4/4 일치 기록이다. 모델/도면 생성 명령을 이번 포장 작업에서 다시 실행한 것으로 세지 않는다. 기존 검증 기록과 이번 모델-부품표 대조를 구분한다.

품질 JSON의 경로를 저장소 상대경로로 바꾼 휴대용 사본을 별도 `*.view.json`으로 제공한다. 원래 정식 품질 JSON과 manifest는 변경하지 않았다. 사본에는 원본 저장소 경로·SHA-256·변환 내용을 기록하며, 상태·수치·판정값은 유지한다.

## 완료 범위와 향후 단계

기준 설계 자료의 완성과 실물 적합성은 각각의 상태로 기록한다. 현재 `scope=reference_design_only`, `actual_specimen_available=false`, `physical_test=not_tested`, `manufacturing_release=false`다. 실사용 하중·토크는 `null`이다.

현재 기준 설계 자료는 추가 실물 입력 없이 참조할 수 있다. 향후 실물 시험으로 범위를 바꾸면 실제 제품·받침면·체결재·계측 조건을 식별하고 [기존 시험 계획](usb-hub-physical-test-plan.md)을 적용한다. 디지털 자료의 완료로 시험 상태나 제조 승인을 자동으로 바꾸지 않는다.
