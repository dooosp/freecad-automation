# Coolgear 기준 설계 검토 마무리

2026-09-17. 대상은 **Coolgear CG-U3MINI4PH-G2의 R1 기준 설계**다. 공개 제조사 자료 대조, 형상·계산 검토와 실물 시험 문서 준비를 마무리했다. M3×10은 형상 검토 후보이며, 원본 R1의 M3×12 구성은 보존한다.

**같은 날의 추가 검토:** [공칭 편심 검토](usb-hub-reference-eccentricity.md)에서 볼트·와셔 중심 이동을 비교했다. 넓은 NBK 비교 와셔는 일부 배치에서 실제 지지 평면 경계에 의해 아래 면적이 줄었다. 아래의 동심 결과와 후속 편심 결과는 각각의 입력 조건으로 읽는다.

실제 보유 허브·패널·체결품·계측기·현장 수행자는 확인되지 않았다. 따라서 `physical_test=not_tested`, `physical_suitability=indeterminate`, `manufacturing_release=false`이며, 체결력·허용 하중·체결 토크는 `null`이다. 검색이나 Pro 자문은 실제 장착·시험 기록을 만들지 않는다.

최종 자료의 `verification.json`은 검증 대상 커밋과 원격 반영 SHA, 실행 결과를 기록한다. `closeout-summary.json`이 계산 결과의 기계 판독 원본이며, 이 문서와 검토 화면은 그 결과를 설명한다.

## 2. 제조사 자료로 식별한 후보

전체 필드·출처·미확인 값은 [부품 자료 JSON](reference-data/usb-hub-fastener-candidates.json)에 있다. 치수의 공칭/최소/최대/미확인을 구분하며, 규격명만으로 열람하지 않은 공차나 경도를 채우지 않는다.

| 위치/역할 | 제조사 품번 | 확인된 표 값 | 현재 지위 |
|---|---|---|---|
| H/M3 후보 볼트, 4개 | norelem `07160-03X10` | M3×10, 8.8급, 머리 외경 5.5·높이 3 mm | 형상 후보 |
| 원본 H 볼트, 4개 | norelem `07160-03X12` | M3×12, 8.8급 | 원본 R1와 대응 |
| P/M5 볼트, 4개 | norelem `07160-05X25` | M5×25, 8.8급, 머리 외경 8.5·높이 5 mm | 기준 외형과 대응 |
| H 너트, 4개 | norelem `07210-03` | M3, 8급, **H 최대 2.4 mm** | 잠금 기능 미지정 평너트 |
| P 너트, 4개 | norelem `07210-05` | M5, 8급, **H 최대 4 mm** | 잠금 기능 미지정 평너트 |
| H 평와셔, 8개 | norelem `07300-03` | 내경×외경×두께 3.2×7×0.5 mm, 강 | 경도·공차 미확인 |
| P 평와셔, 8개 | norelem `07300-05` | 5.3×10×1 mm, 강 | 경도·공차 미확인 |
| H 윗와셔 비교안 | NBK `SWAS-4-8-1-AW` | 4×8×1 mm, SUS304 | 비교만 수행, 설치품 미선정 |

볼트 표의 M3 `Ls min=0`, `Lg max=1.5`, M5 `Ls min=0`, `Lg max=2.4`는 한계 표기다. `Ls=0`인 실제 완전 나사 볼트로 단정하거나 `L−Lg_max`를 너트와의 유효 물림으로 바꾸지 않는다. 머리 DK는 외경이며 실제 머리 밑 받침지름은 별도다. [norelem 볼트 자료](https://www.norelem.fr/en/Product-overview/Flexible-standard-component-system/07000/Nuts-screws-washers-securing-elements/Socket-head-screws-DIN-EN-ISO-4762-enhanced-steel-or-stainless-steel/p/agid.35797).

너트 H는 제조사가 최대높이라고 명시한다. 이번 모델은 다른 치수를 공칭 고정하고 H 최대값을 적용한 **혼합 기준 모델**이다. 너트 높이만 작아지면 돌출은 증가하지만, 현재 돌출값이 전체 공차에서의 최소값은 아니다. 이상적인 육각 CAD와 실제 너트의 모따기·E 치수까지 일치한다고 주장하지 않는다. [norelem 너트 자료](https://www.norelem.fr/en/Product-overview/Flexible-standard-component-system/07000/Nuts-screws-washers-securing-elements/Hexagon-nuts-DIN-934/Hexagon-nuts-DIN-934-steel/p/agid.32698).

와셔의 재질·치수는 확인했으나 열람한 자료에서 경도·두께 공차·평면도의 수치는 확인하지 못했다. NBK의 높이 조절·좌면 확보 용도 설명도 이번 플랜지 조합의 적합성 증명은 아니다. [norelem 평와셔](https://www.norelem.es/en/Product-overview/Flexible-standard-component-system/07000/Nuts-screws-washers-securing-elements/Washers-medium-DIN-EN-ISO-7089-A/p/agid.4120), [NBK 조절 와셔](https://www.nbk1560.com/en-US/products/specialscrew/nedzicom/screwparts/SWAS-AW/).

기존 스페이서 외형 5.5×10×10 mm와 가정 패널 두께 2 mm의 실제 품번·재질·공차·지지 조건은 미확정이다. 유사 카탈로그 부품을 동일 부품으로 간주해 대입하지 않았다. 품번 표는 구매·재고·실사용 선정 결과가 아니다.

## 3. 좌면 비교와 계산 해석

M3×10, 머리 원통 외경 5.5 mm, 허브 접시형 구멍 상부 지름 5.2 mm, 동심 평면 조건이다. H1–H4에서 같은 결과를 얻었다. 아래는 **지정 CAD 형상의 접촉 후보 면적**이다.

| 윗와셔, mm | 머리→와셔, mm² | 와셔→플랜지, mm² | 두 면의 XY 투영 교집합, mm² | 끝–패널 간격, mm | H 최대값 적용 돌출, mm |
|---|---:|---:|---:|---:|---:|
| 기준 3.2×7×0.5 | 15.715817 | 17.247344 | 2.521128 | 5.5 | 1.6 |
| NBK 외형 4×8×1 | 11.191924 | 29.028316 | 2.521128 | 6.0 | 1.1 |

위·아래 면적은 각각 `π(5.5²−d²)/4`, `π(D²−5.2²)/4`로 교차 확인했다. 간격+돌출은 두 구성 모두 7.1 mm다. 비교안은 아래 지지 면적을 늘리지만 위 접촉 후보 면적은 줄인다. 면적만으로 우수품·강도 개선품이라고 선정하지 않는다.

순수 축방향 체결력의 이상화 평형에서 상·하 면은 **직렬 하중 경로**여서 같은 체결력을 전달한다. 면적 비로 하중을 나누거나 두 면에 반씩 배분하지 않는다. 평균 압력 식 `p=F_clamp/A`의 계수 `1/A`는 기준 위/아래 0.063630/0.057980 MPa/N, 비교안 0.089350/0.034449 MPa/N이다. 실제 체결력이 없으므로 압력값은 계산하지 않았다.

투영 교집합 2.521128 mm²는 실제 압력 식의 분모, 전달 하중 비율, 강도 비율 또는 안전율이 아니다. 동심 조건에서 유효 머리 받침지름을 5.2 mm 이하로 가정하면 교집합이 0이지만, 와셔 굽힘에 의한 전달능력 0이나 무한 압력을 뜻하지 않는다. 이 동심 검토에 없던 공칭 XY 편심과 지지 평면 경계는 후속 문서에서 별도로 비교했다. 실제 모따기·필렛·제작 공차/기울기를 포함한 조립 여유 전체·접촉압 분포·열전달 영향은 미확정이다.

원본 CAD 좌표는 판 아랫면 Z=0, 허브 접촉면 Z=4, 패널 윗면 Z=−10이다. 위 면을 와셔 두께만큼 −Z 이동시켜 아래 면에 투영한다. 결과 JSON에 네 위치의 좌표·면 번호·이동 벡터·원환 식 대비 오차를 기록한다. 평면/검색 상자 허용값은 10⁻⁶ mm, 면적 검산 허용값은 10⁻⁶ mm², 체적 간섭 검출 문턱은 10⁻⁵ mm³다. 구멍 중심 비교의 0.10 mm와 다른 수치 기준이다. 검색 상자만 확장하며 CAD 형상은 부풀리지 않는다.

## 4. 확정할 수 있는 계산과 미확정 정격

- **공차:** [체결 적층 검토](usb-hub-reference-joint-review.md)의 일반식을 유지한다. 판 두께만 3.9–4.1 mm로 바꾸면 M3×10 돌출 1.5–1.7, 간격 5.4–5.6 mm다. M5×25 돌출 2.9–3.1, 패널 뒤 돌출 7.9–8.1 mm다. 나머지 치수는 고정하고 너트 H 최대값을 쓴 민감도이며 전체 보증 구간이 아니다.
- **조작 하중:** `M_total=r×F+M_direct`에서 실제 힘 벡터·작용점·사용 방향이 필요하다. 기존 1 N/43.2 mm 팔 길이 예의 0.0432 N·m는 단위 환산 검산이다. 실제 조작력, 볼트별 반력, 하중 정격으로 전용하지 않는다. 자중과 H/P 체결계 사이 내부 전달력은 중복 합산하지 않는다.
- **토크:** 필요한 잔류 체결력과 허용 최대 체결력을 먼저 정해야 한다. 접촉/분리·미끄럼·지렛대 효과, 볼트/나사산·와셔·플랜지·패널 강도, 마찰·체결 공구 산포와 축력 손실이 빠져 있으므로 8.8/8급만으로 토크를 정하지 않는다. [Bossard 체결력·토크 자료](https://assets.eu.ctfassets.net/0vp0u5uh75zd/3S40LEUM235Qk3rJk2phR1/c715f9f45232756c12b59aa681c7fede/060_074_Preload_tightening_torques_Fastening_EN_01_2025.pdf).
- **열:** 정상상태에서 모든 전기 유입·유출 경로를 포함한 전력 차가 열 방출량의 근거가 된다. 실제 손실·열저항·접촉·대류 조건이 없어 온도를 예측하지 않았다. 12 V×4 A 어댑터 정격을 허브 발열 48 W로 쓰지 않으며, 포트별 2 A를 네 포트 동시 허용 총량으로 확대하지 않는다. 0–55 °C 동작환경도 케이스 표면 허용온도가 아니다. [Coolgear 사양](https://www.coolgear.com/wp-content/uploads/CG-U3MINI4PH-G2-Technical-Data-Sheet-06-241119.pdf), [제품 페이지](https://www.coolgear.com/product/4-port-usb-3-2-gen-2-mini-powered-hub-w-esd-surge-protection-power-adapter).

## 5. 실물 판단을 재개하는 조건

| 부족한 입력 | 필요한 근거 | 열리는 판단 |
|---|---|---|
| 실제 구성 | 제품/리비전, 판·스페이서·패널 재질/치수/지지/방향, 체결품 로트 | 실물 장착·자중·구성 대응 |
| 전체 치수 구간 | 볼트 길이·완전 나사부, 너트, 와셔·플랜지·스페이서·패널 공차/평면도 | 최소 간격·유효 물림 |
| 체결 강도·마찰 | 머리 받침면, 와셔 굽힘/경도, 플랜지/패널 강도, 마찰·축력 손실 | 체결력·토크·강도 |
| 서비스 하중 | 케이블/플러그·조작 방향, 힘·작용점, 질량/무게중심, 요구조건 | 시험 힘·모멘트·중단선 |
| 열·전기 조건 | 실제 전력 예산, 부하, 온도 한계, 공기 흐름, 계측 불확도 | 통전·온도 비교와 적합성 |
| 수행 수단 | 현장 수행자, 지그, 교정된 계측기, 독립 로거·차단 | 실제 장착·하중·열 시험 수행 |

[실물 시험 절차](usb-hub-physical-test-plan.md)와 [빈 기록 양식](templates/usb-hub-physical-test.template.json)을 함께 전달한다. 조건이 갖춰지면 무전원 맞춤 → 체결·정상 조작력 → 정적 하중 → 비장착/장착 열·USB 비교 순서로 수행한다. 양식의 빈 값·제안값은 실제 측정이나 채택된 시험 한계가 아니다.

이는 외주를 전제로 한 계획이 아니다. 현재 연결된 장비와 실물 근거가 없어 물리 단계만 미수행으로 남긴 것이다. 기록이 확보되면 계산·판정·보고를 이어갈 수 있다.

## 6. 최종 자료와 재현

로컬 `output/usb-hub-reference-mount/closeout/`에 다음을 제공한다.

- `index.html`, `closeout-summary.json`, `bearing-comparison.json`: 최종 검토 화면·계산·면 참조.
- `catalog-candidates.json`, `source-access-ledger.json`: 품번별 출처·접근일·확인 필드·캡처 해시.
- `reference-source/`, `candidate-M3x10/`: 보존한 R1와 별도 후보 FCStd/STEP, 입력.
- `reproduce/`, `reproduce.ko.md`: 길이·좌면·재읽기·산술 검사를 다시 실행하는 스크립트.
- `docs/`, `verification.json`, `checksums.json`: 보고서·절차·빈 양식, 실행/Git 확인 기록, 배포 파일 해시.

원본 제조사 페이지 전체와 비공개 ChatGPT 대화·계정 정보는 배포하지 않는다. 부품 자료는 관찰한 사실을 구조화한 것이며 재료 성적서나 공급사 인증 사본이 아니다. 최종 Pro 의견 중 H 최대값, 직렬 하중 경로, 투영 면적의 해석, 편심 한계, 착수 조건을 반영했다. Pro의 산술 검토와 이 저장소에서 실제 실행한 CAD/검증 기록은 각각 식별한다.
