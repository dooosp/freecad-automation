# FreeCAD Automation 유료 파일럿 제안

기준일: 2026-10-29. 국내 소규모 제조업체·설계 사무소의 반복적인 파라미터 기반 부품 작업을 가정한다. 아래 판매가는 **첫 고객에게 검증할 제안 가격**이며, 매출·고객 인터뷰·실제 지불 의사 데이터로 확인된 가격은 아니다.

실제 고객 설명에는 [고객용 소개 페이지·제안서·데모 키트](sales/README.md)를 사용한다. 이 문서의 원가·회수 기간 표는 내부 가정이며 고객 성과 사례가 아니다.

## 권장 판매 형태와 금액

**첫 상품은 부가세 별도 990,000원의 유료 파일럿**으로 제안한다. 현재 MIT 소스는 유지하고, 고객이 비용을 지불하는 대상은 설치, 고객별 자동화 설정, 결과 검수, 재실행 가능한 작업 인계와 제한된 지원이다.

| 상품 | 제안 금액 | 제공 범위와 전환 조건 |
| --- | ---: | --- |
| 소스 직접 사용 | 소스 이용료 0원 권장 | 기존 MIT 라이선스 유지. 자체 설치·운영. 포함된 지원이나 제조 승인 없음 |
| 첫 유료 파일럿 | **990,000원 / 1건** | 회사 1곳, 합의한 실행 환경 1개, 부품군 1개, 파라미터 조합 최대 10개, 설정 수정 2회, 인계 후 2주 안에 총 2시간 원격 지원 |
| 파일럿 이후 업무 적용 | **2,000,000–5,000,000원 / 구축 건** | 파일럿 검수와 시간 절감이 확인된 뒤 고객 템플릿·업무 범위별 견적. 복잡한 조립·추가 플랫폼은 별도 범위 |
| 선택 유지보수 | **100,000–300,000원 / 월** | 예: 월 10만 원은 자동화 흐름 1개·지원 1시간, 월 30만 원은 흐름 최대 3개·지원 3시간. 신규 기능·현장 출장은 별도 |

파일럿 이후의 금액은 후속 제안 범위다. 지금 당장 구독형 SaaS, 다중 사용자 클라우드, Windows/Linux 검증 완료, 기업 SLA, 공식 DELMIA 통합을 제공한다고 표시하지 않는다. 원격 지원은 고객이 요청하고 승인한 세션에서만 진행하며, 자동 원격 접속이나 진단 전송 기능은 없다.

Fusion 연 결제의 월 환산은 85,250원이며, 월 결제를 12개월 유지하면 1,531,200원이다. 한시적 다좌석 할인은 비교에서 제외했다. Shapr3D의 검색 결과·초기 마크업에는 과거 Pro US$299 문구가 남아 있었지만, 실제 로딩 완료 화면의 Solo/Studio 상품을 기준으로 기록했다. 가격·세금·지역·상품 구성은 견적 전에 다시 확인한다.

**가격 판단:** 기본 소프트웨어에 무료 대안이 있으므로, 첫 판매의 근거는 독점 코드가 아니라 고객이 반복 작업을 줄이고 검수 가능한 산출물을 받는 경험이다. 이번 개선은 그 중 환경 점검, 첫 산출물 확인, 배포 경계와 오류 복구 안내를 강화한다. 개선 자체가 고객의 지불 의사를 입증하지는 않는다.

## 파일럿에 포함할 인도물

- 실행 환경과 지원 버전을 기록한 설치 확인 결과. 우선 검증된 macOS + FreeCAD 1.1.x 경로로 시작한다.
- 고객과 합의한 부품군 설정 및 최대 10개 파라미터 조합 목록. 기존 지원 형상과 명시한 치수 관계에 한정한다.
- 실제 생성된 STEP/STL과 기존 create-quality JSON, output-manifest 및 artifact-manifest. 파일 존재만으로 형상 검증 완료라고 하지 않는다.
- 재실행 명령, 입력 설정, 실패 시 복구 절차와 인계 설명. 도면·보고서 추가는 파일럿 범위에 포함하는 경우 명시적으로 기록한다.
- 합의한 입력에 대한 소프트웨어 검수 기록과 사람의 검토 대상 목록. 생성된 품질 보고서는 실물 검사 근거가 아니다.

지원 경로는 **고객이 쓰기 권한을 가진 소스 체크아웃**이다. 현재 전역 설치의 기본 출력 위치는 패키지 설치 폴더를 기준으로 하므로 전역 설치를 고객의 표준 사용 경로로 안내하지 않는다. npm 패키지 설치 검증은 배포 내용과 CLI 진입점 검증이며, 모든 전역 설치 작업 흐름의 지원 보증은 아니다. FreeCAD 실행 파일은 함께 재포장하지 않는다. 기존 [MIT 라이선스](../LICENSE)와 별도 구성요소의 고지를 유지한다.

## 검수 기준

1. 같은 설정으로 두 번 실행해 각각 별도 출력 디렉터리에 결과가 남는다. 기존 고객 파일을 덮어쓰지 않는다.
2. 합의한 최대 10개 조합 각각에서 필요한 STEP/STL이 비어 있지 않고, strict create-quality 검사를 통과한다. 누락·실패 조합은 성공으로 합산하지 않는다.
3. STEP 재읽기 등 런타임 검증 근거를 실제 JSON에서 확인한다. 환경 확인만 성공한 상태는 `ready`이고 데모는 `not_requested`다. 실제 생성·품질 검증 성공인 `demo_passed`와 구분한다.
4. 도면/PDF가 계약 범위에 있으면 해당 생성·품질·표시 검사를 별도로 수행한다. create 데모 하나로 도면·FEM·전체 기능을 검증했다고 하지 않는다.
5. 고객의 기존 방식과 자동화 방식에 대해 **사람이 투입한 시간**과 **전체 완료 시간**을 각각 기록한다. 수동 수정 시간과 실패·재시도도 포함한다.
6. 제조 승인, 실물 공차 충족, 안전성 인증, 생산 준비 완료는 이 소프트웨어 검수로 대체하지 않는다. 기존 readiness 보류 조건과 inspection_evidence 경계는 유지한다.

실제 고객의 입력과 요구사항이 없으므로 이번 저장소 개선에서 고객별 10개 조합의 납품이나 절감 시간을 완료했다고 주장하지 않는다. 제공되는 검증 브래킷 데모는 설치와 샘플 실행 경로의 확인이다.

## 판매 전 수익성과 고객 가치 점검

아래는 **가정 계산**이다. 시장 평균 인건비, 관측 매출 또는 절감 보장으로 사용하지 않는다.

파일럿 내부 작업을 설치 2시간 + 자동화 설정 4시간 + 검수·인계 2시간 + 지원 2시간 = 10시간으로 잡고, 내부 시간 비용을 50,000원/시간으로 가정한다. 직접 시간 비용은 500,000원, 20% 예비 비용을 포함하면 600,000원이다. 990,000원에서 남는 금액은 390,000원(약 39%)이며, 영업·일반 관리·세금 등은 아직 제외되어 있다. 이 범위를 넘는 요청은 새 견적으로 분리해야 한다.

고객 월 절감액 가정 = 월 반복 횟수 × 건당 절감 분 ÷ 60 × 고객 시간 비용.

| 가정 시나리오 | 월 반복 | 건당 절감 | 고객 시간 비용 | 계산상 월 절감 | 99만 원 회수 기간 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 사용 빈도 낮음 | 10회 | 10분 | 30,000원/시간 | 50,000원 | 19.8개월 |
| 중간 사용 | 20회 | 15분 | 40,000원/시간 | 200,000원 | 5.0개월 |
| 반복 작업 많음 | 40회 | 20분 | 40,000원/시간 | 약 533,000원 | 약 1.9개월 |

이 계산은 유지보수비·고객 도입 시간·실패 수정 비용을 빼기 전이다. 시간 절감이 없거나 음수이면 회수 기간을 제시하지 않는다. 사용 빈도가 낮은 고객에게는 파일럿의 경제성이 약할 수 있다.

첫 3건에서 다음을 기록한 뒤 가격을 조정한다: 견적 수락 여부와 이유, 실제 구축·지원 시간, 조합별 성공/실패 수, 수동 수정 시간, 고객 작업 시간 전후 차이, 재구매·유지보수 선택 여부. 표본 3건은 일반적인 시장 수요를 입증하는 자료가 아니다. 높은 지원 부담이 확인되면 판매 범위를 좁히거나 구축비를 재산정한다.

## 이번에 제공하는 첫 실행 경로

[고객 첫 실행 안내](customer-start.ko.md)에 따라 `npm run customer:quickcheck`로 환경을 확인하고, `--create-demo`로 실제 검증 브래킷 산출물을 만든다. 이 경로는 설치 프로그램·결제·원격 지원 서비스가 아니며, 프로그램 설치나 외부 전송을 자동으로 하지 않는다.
